3riage computes temporal ownership: whose turn it is to act, reviewer feedback, and open bounty bids.

Connect Your GitHub

GitHub OAuth is not configured on this server yet. You can run 3riage locally in one command using your existing gh session, or configure GitHub OAuth for public hosting.

Option A — Run locally via CLI (zero setup)
pipx install git+https://github.com/Olalolo22/3riage.git
3riage ui
Option B — Enable 1-Click OAuth on this deployment

Set GITHUB_OAUTH_CLIENT_ID, GITHUB_OAUTH_CLIENT_SECRET, and SESSION_SECRET in your deployment environment.
